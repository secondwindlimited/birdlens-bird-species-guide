# How to identify the Lilac-breasted Roller (*Coracias caudatus*)

A stocky roller with a large head, a vivid lilac chest, rusty cheeks and a greenish crown. It often watches from a high perch in open, lightly wooded country across eastern and southern Africa. Its bold colours are hard to miss; a tumbling display flight or a harsh, rasping call can also draw attention to it.

## What kind of bird is it?

| | |
|---|---|
| Common name | Lilac-breasted Roller |
| Scientific name | *Coracias caudatus* |
| Order | Coraciiformes |
| Family | Coraciidae |
| Genus | *Coracias* |
