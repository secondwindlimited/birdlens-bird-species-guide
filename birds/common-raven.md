# How to identify the Common Raven (*Corvus corax*)

The Common Raven is a very large, all-black bird with a heavy, slightly hooked bill and a long tail that narrows to a point. In flight, its broad, swept wings and measured wingbeats help distinguish it from crows. It occurs across much of the Northern Hemisphere, in settings ranging from open tundra and deserts to forests and rugged coasts.

## What kind of bird is it?

| | |
|---|---|
| Common name | Common Raven |
| Scientific name | *Corvus corax* |
| Order | Passeriformes |
| Family | Corvidae |
| Genus | *Corvus* |
