# How to identify the Oriente Warbler (*Teretistris fornsi*)

Look for a small Cuban warbler with slate-gray upperparts, bright yellow on the face and upper breast, and a pale lower belly. It often moves in noisy groups through trees and dense scrub. The species occurs in eastern Cuba and nearby islands, from dry coastal woodland to wetter mountain forest.

## What kind of bird is it?

| | |
|---|---|
| Common name | Oriente Warbler |
| Scientific name | *Teretistris fornsi* |
| Order | Passeriformes |
| Family | Teretistridae |
| Genus | *Teretistris* |
