# How to identify the Long-tailed Koel (*Urodynamis taitensis*)

An outsized cuckoo with a very long, softly rounded tail, brown upperparts and bold dark marks across its pale underside is distinctive in flight or by its ringing, rising whistle. It breeds in forest across New Zealand, often high in the canopy, then leaves for islands in the tropical Pacific. It can be heard more readily than seen.

## What kind of bird is it?

| | |
|---|---|
| Common name | Long-tailed Koel |
| Scientific name | *Urodynamis taitensis* |
| Order | Cuculiformes |
| Family | Cuculidae |
| Genus | *Urodynamis* |
