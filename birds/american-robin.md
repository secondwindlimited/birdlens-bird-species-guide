# How to identify the American Robin (*Turdus migratorius*)

A familiar North American thrush with a brick-orange breast, grey-brown back and dark head. A broken white ring around the eye and a yellow bill stand out at close range. Robins run and pause on lawns as they hunt earthworms, and their rich, carolling song is among the first to be heard before dawn in spring.

## What kind of bird is it?

| | |
|---|---|
| Common name | American Robin |
| Scientific name | *Turdus migratorius* |
| Order | Passeriformes |
| Family | Turdidae |
| Genus | *Turdus* |
