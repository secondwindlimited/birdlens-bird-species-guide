# How to identify the Red Wattlebird (*Anthochaera carunculata*)

A large, streaky grey-brown honeyeater with a dark cap, red eye, pink skin flaps beside the neck and a vivid yellow patch near the tail. Its coarse, far-carrying calls are often heard around flowering trees. Look for it across southern mainland Australia, where it may drive smaller birds from a rich source of nectar.

## What kind of bird is it?

| | |
|---|---|
| Common name | Red Wattlebird |
| Scientific name | *Anthochaera carunculata* |
| Order | Passeriformes |
| Family | Meliphagidae |
| Genus | *Anthochaera* |
