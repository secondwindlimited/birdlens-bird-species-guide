# How to identify the Great Jacamar (*Jacamerops aureus*)

The Great Jacamar is a bulky bird with shining green upperparts, a long black bill and rich orange-rufous underparts. It often sits quietly among the middle and upper canopy, alone or with a mate, and can be easy to overlook. Search lowland tropical forest from Central America south into South America, or listen for its falling whistle.

## What kind of bird is it?

| | |
|---|---|
| Common name | Great Jacamar |
| Scientific name | *Jacamerops aureus* |
| Order | Piciformes |
| Family | Galbulidae |
| Genus | *Jacamerops* |
