# How to identify the Corn Crake (*Crex crex*)

An elusive rail of damp, tall grass, it is more often heard than seen. Its repeated, rough two-part call carries across meadows, especially around dawn and dusk and sometimes at night. If flushed, it shows rich chestnut wings against a brown, streaked body, with a grey face and breast and a stout pinkish bill. Look for it in hayfields and other quiet grasslands.

## What kind of bird is it?

| | |
|---|---|
| Common name | Corn Crake |
| Scientific name | *Crex crex* |
| Order | Gruiformes |
| Family | Rallidae |
| Genus | *Crex* |
