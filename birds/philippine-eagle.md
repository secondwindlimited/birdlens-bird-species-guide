# How to identify the Philippine Eagle (*Pithecophaga jefferyi*)

A very large eagle with a shaggy, streaked crest, white underparts, dark upperparts, and a massive gray bill. Its broad wings make it look especially wide in flight. The Philippine Eagle is found only in the Philippines, where it lives in lowland and mountain forests. It is extremely rare and does not migrate.

## What kind of bird is it?

| | |
|---|---|
| Common name | Philippine Eagle |
| Scientific name | *Pithecophaga jefferyi* |
| Order | Accipitriformes |
| Family | Accipitridae |
| Genus | *Pithecophaga* |
