# How to identify the Woodland Kingfisher (*Halcyon senegalensis*)

The Woodland Kingfisher is a medium-sized bird with vivid blue upper wings and a red-and-black bill, a useful combination in the field. It is usually found in wooded country rather than beside water, including dry woodland, tree-lined river margins and forest borders. Listen for its piercing opening whistle followed by a descending trill; it may call from an exposed perch.

## What kind of bird is it?

| | |
|---|---|
| Common name | Woodland Kingfisher |
| Scientific name | *Halcyon senegalensis* |
| Order | Coraciiformes |
| Family | Alcedinidae |
| Genus | *Halcyon* |
