# How to identify the Painted Stork (*Mycteria leucocephala*)

Look for a large, pale stork with a deep yellow bill whose end bends down, an orange bare face, dark wing panels and pink feathers trailing over the back. Adults also show a dark, finely marked breast band. It is most often found around freshwater wetlands, marshes and flooded fields across the Asian plains.

## What kind of bird is it?

| | |
|---|---|
| Common name | Painted Stork |
| Scientific name | *Mycteria leucocephala* |
| Order | Ciconiiformes |
| Family | Ciconiidae |
| Genus | *Mycteria* |
