# How to identify the Russet-crowned Motmot (*Momotus mexicanus*)

A small motmot with a rusty-red crown, green body and long blue tail ending in dark racket-like tips. Its black face patch is edged with blue and violet. Look for it in western Mexico, where it sits quietly among trees in tropical forest, woodland and gardens. A slow side-to-side tail movement can help reveal a bird that might otherwise blend into the foliage.

## What kind of bird is it?

| | |
|---|---|
| Common name | Russet-crowned Motmot |
| Scientific name | *Momotus mexicanus* |
| Order | Coraciiformes |
| Family | Momotidae |
| Genus | *Momotus* |
