# How to identify the Kakapo (*Strigops habroptilus*)

The kākāpō is a very large, round-bodied parrot with moss-green plumage marked in yellow and dark mottling. Its pale, owl-like face, heavy build and ground-dwelling habits make it unlike most other parrots. It cannot fly and is active at night. Today, it is found only on a few predator-free islands off New Zealand.

## What kind of bird is it?

|---|---|
| Common name | Kakapo |
| Scientific name | *Strigops habroptilus* |

| Genus | *Strigops* |
