# How to identify the Red-winged Starling (*Onychognathus morio*)

A glossy, dark starling with rusty-red wing panels that flash in flight. Males have dark heads, while females show grey on the head and upper chest. It lives across eastern and southern Africa, where it is often seen on rocky cliffs and outcrops, or around buildings in towns and cities.

## What kind of bird is it?

| | |
|---|---|
| Common name | Red-winged Starling |
| Scientific name | *Onychognathus morio* |
| Order | Passeriformes |
| Family | Sturnidae |
| Genus | *Onychognathus* |
