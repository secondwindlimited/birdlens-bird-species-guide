# How to identify the Common Flameback (*Dinopium javanense*)

A small, golden-backed woodpecker with a red rump, a white throat and a black nape. Males show a red crest; females have a dark, white-streaked crest. Listen for a sharp, rattling trill. It lives in forest and scrub in parts of India and Southeast Asia, where it is more likely to be found away from towns.

## What kind of bird is it?

| | |
|---|---|
| Common name | Common Flameback |
| Scientific name | *Dinopium javanense* |
| Order | Piciformes |
| Family | Picidae |
| Genus | *Dinopium* |
