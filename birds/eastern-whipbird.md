# How to identify the Eastern Whipbird (*Psophodes olivaceus*)

Look for a slim, olive-backed bird with a dark face and chest, a small raised crest and a bright white throat mark. It usually stays low in thick forest, so its ringing paired call is often the first clue: one bird gives a drawn-out whistle and a sharp, whip-like burst, followed by its partner’s brief notes. It lives in eastern Australia’s wet forests.

## What kind of bird is it?

| | |
|---|---|
| Common name | Eastern Whipbird |
| Scientific name | *Psophodes olivaceus* |
| Order | Passeriformes |
| Family | Psophodidae |
| Genus | *Psophodes* |
