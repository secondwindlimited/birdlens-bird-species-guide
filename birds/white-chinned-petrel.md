# How to identify the White-chinned Petrel (*Procellaria aequinoctialis*)

A large, dark petrel with a conspicuously pale, ivory-toned bill. The small white patch beneath the bill is often hard to spot, so bill colour and size are more useful clues. It ranges widely over the Southern Ocean and moves north after breeding; birdwatchers may encounter it in the Humboldt Current off South America.

## What kind of bird is it?

| | |
|---|---|
| Common name | White-chinned Petrel |
| Scientific name | *Procellaria aequinoctialis* |
| Order | Procellariiformes |
| Family | Procellariidae |
| Genus | *Procellaria* |
