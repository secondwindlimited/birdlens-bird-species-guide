# How to identify the Martial Eagle (*Polemaetus bellicosus*)

A huge eagle with a noticeable short crest and broad wings. Adults have a dark brown head, back and chest, set against a pale, blotched belly; their underwings look brown in flight. It lives across much of sub-Saharan Africa, where it is usually seen alone or in pairs over open woodland, savanna and other lightly wooded country.

## What kind of bird is it?

| | |
|---|---|
| Common name | Martial Eagle |
| Scientific name | *Polemaetus bellicosus* |
| Order | Accipitriformes |
| Family | Accipitridae |
| Genus | *Polemaetus* |
