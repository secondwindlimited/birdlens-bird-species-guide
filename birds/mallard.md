# How to identify the Mallard (*Anas platyrhynchos*)

The most familiar duck across the Northern Hemisphere. Breeding males have a glossy green head, a narrow white neck ring, a chestnut breast and a yellow bill. Females are mottled brown with an orange bill marked with dark blotches. Both sexes show a blue-purple wing patch edged in white, visible in flight and often at rest.

## What kind of bird is it?

| | |
|---|---|
| Common name | Mallard |
| Scientific name | *Anas platyrhynchos* |
| Order | Anseriformes |
| Family | Anatidae |
| Genus | *Anas* |
