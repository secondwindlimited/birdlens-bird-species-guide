# How to identify the Greater Rhea (*Rhea americana*)

A Greater Rhea is a huge, flightless South American bird with a small head, shaggy gray-brown feathers and long, powerful legs. Males are darker than females, especially around the neck and back. It is most likely to be seen in open grassland or savanna, sometimes in a large flock. Look for it running with its wings held out for balance.

## What kind of bird is it?

| | |
|---|---|
| Common name | Greater Rhea |
| Scientific name | *Rhea americana* |
| Order | Rheiformes |
| Family | Rheidae |
| Genus | *Rhea* |
