# How to identify the Thick-billed Parrot (*Rhynchopsitta pachyrhyncha*)

This large-billed, green parrot is recognised by its red brow and small red marks on the shoulders. In flight, a yellow band stands out beneath each wing. It is usually seen or heard in groups in the high conifer forests of Mexico’s Sierra Madre Occidental, where its loud, rolling calls can carry a long way.

## What kind of bird is it?

| | |
|---|---|
| Common name | Thick-billed Parrot |
| Scientific name | *Rhynchopsitta pachyrhyncha* |
| Order | Psittaciformes |
| Family | Psittacidae |
| Genus | *Rhynchopsitta* |
