# How to identify the Green Hylia (*Hylia prasina*)

The Green Hylia is a small, quiet-looking forest bird, mainly olive in colour, with a pale line above the eye and a light throat. Its clear, piercing two-part whistle often reveals it before it is seen. Look for it among foliage in the middle levels of humid African forests, including at forest edges and openings.

## What kind of bird is it?

| | |
|---|---|
| Common name | Green Hylia |
| Scientific name | *Hylia prasina* |
| Order | Passeriformes |
| Family | Hyliidae |
| Genus | *Hylia* |
