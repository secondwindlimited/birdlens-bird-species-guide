# How to identify the Black Catbird (*Melanoptila glabrirostris*)

The Black Catbird is a slim, glossy black mimid with a narrow, short bill and a long tail. It often stays low in dense growth, where it can be hard to spot, but sings from exposed perches. On Cozumel it is fairly frequent; on the Yucatán mainland it is much less often encountered.

## What kind of bird is it?

| | |
|---|---|
| Common name | Black Catbird |
| Scientific name | *Melanoptila glabrirostris* |
| Order | Passeriformes |
| Family | Mimidae |
| Genus | *Melanoptila* |
