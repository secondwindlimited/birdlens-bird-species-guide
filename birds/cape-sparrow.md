# How to identify the Cape Sparrow (*Passer melanurus*)

An unstreaked sparrow with a warm chestnut back, the Cape Sparrow is easiest to pick out by the male’s dark head and bold pale curve beside the face. Females are greyer and less sharply marked. It is a year-round bird of southern Africa, often encountered in open scrub, farmland, gardens and other settled places.

## What kind of bird is it?

| | |
|---|---|
| Common name | Cape Sparrow |
| Scientific name | *Passer melanurus* |
| Order | Passeriformes |
| Family | Passeridae |
| Genus | *Passer* |
