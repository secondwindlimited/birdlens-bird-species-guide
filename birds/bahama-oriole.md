# How to identify the Bahama Oriole (*Icterus northropi*)

Look for a black-and-yellow oriole with a dark head, back and chest, bright yellow underparts, and yellow shoulders. It lives on Andros in the Bahamas and stays there year-round. Watch for it in palm-rich woodland, pine forest and broadleaf scrub, as well as in gardens and parks where it searches for flowers and fruit.

## What kind of bird is it?

| | |
|---|---|
| Common name | Bahama Oriole |
| Scientific name | *Icterus northropi* |
| Order | Passeriformes |
| Family | Icteridae |
| Genus | *Icterus* |
