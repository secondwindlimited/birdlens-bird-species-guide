# How to identify the Snow Goose (*Anser caerulescens*)

The Snow Goose is a medium-sized goose with either mostly white plumage and black outer flight feathers, or a slate-colored body and pale face. Its pinkish bill has a dark, curved edge where it meets the face. Look for it in noisy flocks in fields, wetlands and lakes during migration and winter; it breeds on Arctic tundra.

## What kind of bird is it?

| | |
|---|---|
| Common name | Snow Goose |
| Scientific name | *Anser caerulescens* |
| Order | Anseriformes |
| Family | Anatidae |
| Genus | *Anser* |
