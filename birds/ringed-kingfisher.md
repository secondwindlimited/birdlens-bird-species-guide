# How to identify the Ringed Kingfisher (*Megaceryle torquata*)

A very large kingfisher with a heavy, dagger-like bill, shaggy blue-gray crest and rusty underparts. The male has a plain rusty chest; the female shows a blue-gray chest band edged in white. Watch along rivers, lakes and other fish-rich waters from southern Texas through Central and South America, or listen for its loud, rough calls.

## What kind of bird is it?

| | |
|---|---|
| Common name | Ringed Kingfisher |
| Scientific name | *Megaceryle torquata* |
| Order | Coraciiformes |
| Family | Alcedinidae |
| Genus | *Megaceryle* |
