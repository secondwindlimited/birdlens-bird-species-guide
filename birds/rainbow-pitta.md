# How to identify the Rainbow Pitta (*Pitta iris*)

The Rainbow Pitta is a compact, dark bird with a green back and wings, a vivid blue flash on the shoulder and scarlet feathers beneath the tail. It searches among fallen leaves, usually hopping on the ground. Look for it in northern Australia’s Top End and coastal Kimberley, where it is the resident pitta.

## What kind of bird is it?

| | |
|---|---|
| Common name | Rainbow Pitta |
| Scientific name | *Pitta iris* |
| Order | Passeriformes |
| Family | Pittidae |
| Genus | *Pitta* |
