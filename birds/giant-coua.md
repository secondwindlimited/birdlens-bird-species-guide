# How to identify the Giant Coua (*Coua gigas*)

A very large, long-legged coua with a long tail, rusty-red belly and bare skin around the eyes in blue and pink. It is found in western and southwestern Madagascar, where it usually walks on the ground beneath trees. Listen for a loud, drawn-out call followed by several softer notes. It stays in its range year-round.

## What kind of bird is it?

| | |
|---|---|
| Common name | Giant Coua |
| Scientific name | *Coua gigas* |
| Order | Cuculiformes |
| Family | Cuculidae |
| Genus | *Coua* |
