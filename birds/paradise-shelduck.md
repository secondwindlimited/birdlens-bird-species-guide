# How to identify the Paradise Shelduck (*Tadorna variegata*)

A large, boldly patterned duck found only in New Zealand, the Paradise Shelduck is easiest to sex by its head: adult males are dark-headed, while females have pale heads. In flight, look for a broad white area on each wing. It occurs around lakes, rivers and wetlands, and also feeds on open grassland and farmland.

## What kind of bird is it?

| | |
|---|---|
| Common name | Paradise Shelduck |
| Scientific name | *Tadorna variegata* |
| Order | Anseriformes |
| Family | Anatidae |
| Genus | *Tadorna* |
