# How to identify the Great Green Macaw (*Ara ambiguus*)

The Great Green Macaw is a very large, mostly green parrot with a red forehead, blue on its wings and lower back, and a reddish tail. Its size and bright markings make it distinctive in flight, though it can be difficult to see among canopy leaves. Watch for pairs or small groups above tropical forests. It stays in its range year-round.

## What kind of bird is it?

| | |
|---|---|
| Common name | Great Green Macaw |
| Scientific name | *Ara ambiguus* |
| Order | Psittaciformes |
| Family | Psittacidae |
| Genus | *Ara* |
