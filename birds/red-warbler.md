# How to identify the Red Warbler (*Cardellina rubra*)

An adult Red Warbler is a small, vivid-red bird with a contrasting pale or dark cheek patch. It lives in Mexico’s interior mountains, where it is most often found in humid conifer or pine-oak woodland and nearby scrub. Watch for it moving quickly through foliage, alone with its mate or among other feeding birds.

## What kind of bird is it?

| | |
|---|---|
| Common name | Red Warbler |
| Scientific name | *Cardellina rubra* |
| Order | Passeriformes |
| Family | Parulidae |
| Genus | *Cardellina* |
