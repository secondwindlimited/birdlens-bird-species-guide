# How to identify the Chestnut-capped Piha (*Lipaugus weberi*)

A dark grey, long-tailed piha with a narrow yellow ring around the eye and a chestnut crown that can be difficult to see. It is known only from a small area of Colombia’s Antioquia department. Look for it in humid Andean cloud forest, where its piercing, squeaky calls may reveal it before the bird is seen.

## What kind of bird is it?

| | |
|---|---|
| Common name | Chestnut-capped Piha |
| Scientific name | *Lipaugus weberi* |
| Order | Passeriformes |
| Family | Cotingidae |
| Genus | *Lipaugus* |
