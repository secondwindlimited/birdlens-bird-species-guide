# How to identify the Sun Parakeet (*Aratinga solstitialis*)

A bright, mostly golden parakeet with an orange-red face, green patches on the wings and blue-green flight feathers. Its loud, harsh calls often give it away before it is seen. Look for it in northeastern South America, especially where open savanna meets forest, or beside rivers. It travels in sociable groups and may fly between distant feeding areas.

## What kind of bird is it?

| | |
|---|---|
| Common name | Sun Parakeet |
| Scientific name | *Aratinga solstitialis* |
| Order | Psittaciformes |
| Family | Psittacidae |
| Genus | *Aratinga* |
