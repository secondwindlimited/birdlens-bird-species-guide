# How to identify the Western Corella (*Cacatua pastinator*)

A stocky, white cockatoo with a long, pointed bill, a short crest and a pink mark beside the bill. Blue-grey bare skin surrounds the eye. It is found in southwestern Australia, especially in farmland in the Wheatbelt and the far southwest, but is not usually seen around Perth. Listen for its wavering, worried-sounding call.

## What kind of bird is it?

| | |
|---|---|
| Common name | Western Corella |
| Scientific name | *Cacatua pastinator* |
| Order | Psittaciformes |
| Family | Cacatuidae |
| Genus | *Cacatua* |
