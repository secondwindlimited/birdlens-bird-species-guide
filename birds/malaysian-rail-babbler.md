# How to identify the Malaysian Rail-babbler (*Eupetes macrocerus*)

A slim, brown forest bird with a striking white eyebrow, black stripe through the eye and chestnut throat. Its long legs, tail and bill give it an unusual, almost wader-like outline on the forest floor. It is a resident of the Malay Peninsula and nearby islands, where it keeps to dense forest and can be difficult to spot.

## What kind of bird is it?

| | |
|---|---|
| Common name | Malaysian Rail-babbler |
| Scientific name | *Eupetes macrocerus* |
| Order | Passeriformes |
| Family | Eupetidae |
| Genus | *Eupetes* |
