# How to identify the Anna's Hummingbird (*Calypte anna*)

Look for a stocky, big-headed hummingbird with a green back, gray underside, and straight bill. Adult males flash a vivid pink-red crown and throat, but those patches can appear dark in shade. Anna’s Hummingbird is especially easy to find around gardens and feeders across the Pacific states, and it also uses chaparral and other open scrub.

## What kind of bird is it?

|---|---|
| Common name | Anna's Hummingbird |
| Scientific name | *Calypte anna* |
| Order | Apodiformes |
| Family | Trochilidae |
| Genus | *Calypte* |
