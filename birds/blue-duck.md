# How to identify the Blue Duck (*Hymenolaimus malacorhynchos*)

A compact, slate-coloured duck with a pale pink bill, chestnut marks across the breast and a habit of holding its tail up on the water. The male gives a thin, wheezy whistle; the female makes a rougher, lower call. It occurs only in New Zealand, where it lives beside clear, rushing streams in mountainous country.

## What kind of bird is it?

| | |
|---|---|
| Common name | Blue Duck |
| Scientific name | *Hymenolaimus malacorhynchos* |
| Order | Anseriformes |
| Family | Anatidae |
| Genus | *Hymenolaimus* |
