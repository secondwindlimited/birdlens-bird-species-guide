# How to identify the Senegal Batis (*Batis senegalensis*)

A small, quick-moving bird with a dark cap, pale eyebrow and contrasting chest band. Males have a black band and white eyebrow; females show a russet band and buff eyebrow. Look for it in pairs among scrub and scattered trees across West African savannas, from Senegal east to Nigeria and Cameroon.

## What kind of bird is it?

| | |
|---|---|
| Common name | Senegal Batis |
| Scientific name | *Batis senegalensis* |
| Order | Passeriformes |
| Family | Platysteiridae |
| Genus | *Batis* |
