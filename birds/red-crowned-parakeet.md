# How to identify the Red-crowned Parakeet (*Cyanoramphus novaezelandiae*)

An emerald-green parakeet with a bright red crown, red marks beside the eyes and red patches on the flanks. In flight, look for blue along the wing edge. Its low, musical chatter often gives it away. It is most often found on New Zealand’s offshore islands and in protected mainland sites, though a few scarce populations persist in mainland forests.

## What kind of bird is it?

| | |
|---|---|
| Common name | Red-crowned Parakeet |
| Scientific name | *Cyanoramphus novaezelandiae* |
| Order | Psittaciformes |
| Family | Psittaculidae |
| Genus | *Cyanoramphus* |
