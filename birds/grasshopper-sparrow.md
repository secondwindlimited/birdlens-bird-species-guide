# How to identify the Grasshopper Sparrow (*Ammodramus savannarum*)

Look for a compact sparrow with a low, flattened crown, short tail and warm buff tones. Its breast is plain rather than streaked, while the back shows mixed gray and reddish-brown patterning. A pale eye-ring and yellow mark above the eye help pick it out. It lives in open grassy country, where it may sing from a shrub but often stays hidden in the vegetation.

## What kind of bird is it?

| | |
|---|---|
| Common name | Grasshopper Sparrow |
| Scientific name | *Ammodramus savannarum* |
| Order | Passeriformes |
| Family | Passerellidae |
| Genus | *Ammodramus* |
