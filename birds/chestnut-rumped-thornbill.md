# How to identify the Chestnut-rumped Thornbill (*Acanthiza uropygialis*)

The Chestnut-rumped Thornbill is a tiny, plain grey-brown bird with a clean pale underside and a vivid chestnut patch above its tail. That patch often flashes as it flies between low shrubs. Search for it in dry woodland and scrub across inland Australia, where it feeds in pairs or small groups and sometimes drops to the ground.

## What kind of bird is it?

|---|---|
| Common name | Chestnut-rumped Thornbill |
| Scientific name | *Acanthiza uropygialis* |
| Order | Passeriformes |
| Family | Acanthizidae |
| Genus | *Acanthiza* |
