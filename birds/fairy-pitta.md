# How to identify the Fairy Pitta (*Pitta nympha*)

Look for a small, colourful pitta walking on the forest floor: it has green upperparts, pale buff underparts, a red lower belly and a striking striped head. Its clear, paired whistles can reveal it in dense cover. It breeds in parts of East Asia and moves south for winter, when it may be found in forests as far as Borneo.

## What kind of bird is it?

| | |
|---|---|
| Common name | Fairy Pitta |
| Scientific name | *Pitta nympha* |
| Order | Passeriformes |
| Family | Pittidae |
| Genus | *Pitta* |
