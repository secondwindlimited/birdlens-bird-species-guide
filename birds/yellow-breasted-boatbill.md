# How to identify the Yellow-breasted Boatbill (*Machaerirhynchus flaviventer*)

A small rainforest bird with a broad, flattened bill, bright yellow underparts and a long tail that it often holds at an angle. Males have dark upperparts, while females are olive above; both show white wing markings and a pale throat. Look for it among foliage high in the forest canopy in New Guinea or northern Queensland.

## What kind of bird is it?

| | |
|---|---|
| Common name | Yellow-breasted Boatbill |
| Scientific name | *Machaerirhynchus flaviventer* |
| Order | Passeriformes |
| Family | Machaerirhynchidae |
| Genus | *Machaerirhynchus* |
