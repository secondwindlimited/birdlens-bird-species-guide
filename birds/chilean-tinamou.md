# How to identify the Chilean Tinamou (*Nothoprocta perdicaria*)

The Chilean Tinamou is a compact, almost tailless bird with a chickenlike shape, finely striped brown upperparts and a buff face crossed by a dark eye-line. It lives in central Chile and is often found alone or in small groups near roads, especially at the start and end of the day. It usually runs for cover but may burst into flight if approached.

## What kind of bird is it?

|---|---|
| Common name | Chilean Tinamou |
| Scientific name | *Nothoprocta perdicaria* |
| Order | Tinamiformes |
| Family | Tinamidae |
| Genus | *Nothoprocta* |
