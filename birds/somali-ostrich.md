# How to identify the Somali Ostrich (*Struthio molybdophanes*)

The Somali Ostrich is a very large, flightless bird with a bare, bluish neck and powerful legs. Males show brighter blue skin in the breeding season; females have pale eyes. It occurs in the Horn of Africa, where it can be seen in dry open country, including scrub and semi-desert, usually in small parties.

## What kind of bird is it?

| | |
|---|---|
| Common name | Somali Ostrich |
| Scientific name | *Struthio molybdophanes* |
| Order | Struthioniformes |
| Family | Struthionidae |
| Genus | *Struthio* |
